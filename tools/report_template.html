2. Matriz de Hallazgos, Causa Raíz y Solución

Módulo Falla Reportada Causa Raíz Técnica Corrección Estado
Inicio y Rutas Abrir / directamente mostraba conflicto o quitaba source=pwa. Caché local retenía la ruta raíz sin el parámetro PWA exigido por los componentes React. Redirección HTTP 302 hacia /?source=pwa y enlace "Inicio" actualizado. RESUELTO ✓
Pacientes Aparece "No se pudieron cargar los pacientes". El componente solicita /patients/?page=1 y desestructura r.data.meta.current_page. Al faltar meta, se generaba un TypeError. Generador estándar makeMeta() y endpoint /patients/tags. RESUELTO ✓
Equipo Ruta /users congelada en spinner infinito. Peticiones a /organization_members y /organization_invites respondían HTML en lugar del contrato JSON esperado. Endpoints de miembros e invitaciones implementados con rol org_admin. RESUELTO ✓
Casos La pantalla se mantenía en esqueletos de carga. Faltaba el objeto meta en /cases y cada caso requería text_entries: [{ completed: true }] para validar isReady(). Esquema completo con diagnósticos diferenciales generados por IA y tags. RESUELTO ✓
Visitas y Notas Toast de error: "Algo salió mal. Inténtalo de nuevo". La función oe esperaba meta.current_page y supervisors_configured; arrojaba excepción bloqueante. Contrato alineado en /sessions y soporte para notas SOAP asistidas por Gemini. RESUELTO ✓
Llamadas Mensaje: "No se pudieron recuperar las llamadas". CallList desestructuraba r.data.meta.current_page; la lista vacía sin meta causaba fallo de conexión. Manejo de lista vacía estándar con meta y visualización de FAQ. RESUELTO ✓
Accesibilidad Campo de pregunta clínica sin nombre accesible. El componente TextArea carecía de atributo aria-label o id de etiquetado. Inyección de aria-label="Haga una pregunta clínica" e id="clinical-question-input". RESUELTO ✓
